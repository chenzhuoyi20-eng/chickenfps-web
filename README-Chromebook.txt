CHICKEN FPS — Dell Chromebook 网页版

使用方式
1. 这是网页游戏，不能直接双击 index.html 运行。
2. 把这个 ZIP 原样上传到支持 HTML5/WebGL 的静态网站，解压后必须让 index.html 位于网站根目录。
3. 在 Chromebook 的 Chrome 浏览器打开网站网址，等加载完成后点击游戏画面。
4. 建议全屏游玩，并使用键盘和鼠标。

学校电脑说明
- 学校管理的 Chromebook 可能禁止安装 APK，因此本版本不需要安装程序。
- 如果学校屏蔽了网站、WebGL、鼠标锁定或 Unity Relay，必须请学校管理员允许；本游戏不会尝试绕过学校策略。
- 第一次加载约需下载 40 MB，之后浏览器会缓存主要文件。

主要操作
- WASD：移动
- 鼠标：瞄准；左键：开火；右键：开镜
- 1/2/3：主枪/手枪/刀
- 4/5/6：投掷物
- R：换弹；B：商店；E：互动/下包/拆包
- F：拾取；G：丢枪；V：队伍语音（浏览器与学校权限允许时）
- F2：靶场目标速度；F3：重置统计；F4：重置目标；F5：30 秒挑战

版本适配
- Chromebook 自动使用 45 FPS 低功耗配置。
- 关闭实时阴影与抗锯齿，优先保证普通 Dell Chromebook 的稳定帧率。
- 已内置 Noto Sans CJK SC 中文字体（SIL Open Font License 1.1）。
